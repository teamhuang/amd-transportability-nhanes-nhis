# Reproducibility code and outputs — cross-survey transportability of a self-reported AMD model

This repository accompanies the manuscript:

> **External validation and cross-survey miscalibration of a low-cost model for self-reported age-related macular degeneration across US population surveys**

It contains the analysis code, machine-readable results, derived analytic datasets, figure files and environment used to produce every number and display item in the manuscript. The manuscript is under review; a full citation and the version-specific Zenodo DOI will be added here when available.

## What is included

- `code/` — analysis scripts. Primary chain:
  `build_nhanes.py` → `build_nhis.py` → `harden.py` → `harden2.py` → `sr_derivation.py` →
  `sr_weighted_calibration.py` → `sr_survey_inference.py` → `sr_increment_robust.py` →
  `sr_missing_mi2.py` → `sr_mi_stability.py` → `sr_lipid_sensitivity.py` →
  `sr_final_tables_figs.py` → `make_tables_sr.py` → `make_s6_table.py` → `make_round4_tables_figs.py`.
  Figure files are generated by `make_figures_nature_round17.py`. Verification/audit scripts:
  `verify_round2.py`, `verify_round3.py`, `verify_round4.py`, `audit_round2.py`, `audit_round3.py`,
  `audit_round5.py`, `audit_round7.py`, `audit_survey_round8.py`, `audit_codebook_round12.py`,
  `regen_tables_round12.py`, `audit_consistency_round12.py`, `banned_phrase_audit_round12.py`.
  `code/dev/` holds exploratory probes and superseded scripts kept for transparency.
- `results/` — all machine-readable outputs (JSON/CSV) and run logs, including the authoritative
  full-precision coefficients (`model_equation.json`, key `coefficients_full_precision`), the codebook
  audit (`sr_codebook_audit.json`) and the table-regeneration check (`sr_table_regen.json`).
  **`results/legacy/` holds outputs of an earlier spline-age fit; see its README. Do not use those files
  to reproduce the manuscript.**
- `derived_data/` — the two analytic datasets used for all reported numbers
  (`nhanes_derivation.csv`, `nhis_external.csv`). Raw NCHS transport files are **not** redistributed;
  download them from CDC/NCHS (links below).
- `documentation/` — variable-harmonisation dictionary, endpoint-code audit log and the design-freeze/admission record.
- `figures/` — the nine final manuscript figures (PDF + PNG, Nature-style, 5.0 × 5.0 or 6.5 × 5.0 cm).
- `environment/` — exact package versions (`requirements.txt`, `environment.txt`).

## Data sources

- NHANES 2005–06 and 2007–08 public-use files: <https://wwwn.cdc.gov/nchs/nhanes/>
- NHIS 2016 and 2017 Sample Adult public-use files: <https://ftp.cdc.gov/pub/Health_Statistics/NCHS/Datasets/NHIS/>

Both are de-identified public-use files released by the US National Center for Health Statistics. The derived datasets in `derived_data/` contain only variables from these files; no controlled-access data were used.

## How to reproduce

1. Install Python 3.10 and the packages in `environment/requirements.txt`.
2. Download the NHANES and NHIS files listed above and place them where `build_nhanes.py` and
   `build_nhis.py` expect them (paths are defined at the top of each script).
3. Run the primary chain in the order shown above.
4. Rebuild the display tables with `make_tables_sr.py`, `make_s6_table.py` and
   `make_round4_tables_figs.py`.
5. Rebuild the figures with `make_figures_nature_round17.py`.
6. Verify the outputs with `regen_tables_round12.py`, `audit_codebook_round12.py`,
   `audit_consistency_round12.py` and `verify_round4.py`.

The manuscript's main text carries 4 figures and 4 tables; Supplementary Tables S1–S19 and Supplementary Figs S1–S5 are in the separate Supplementary Information file submitted with the manuscript.

## Important notes

- **Figure generation.** The figure blocks in `sr_final_tables_figs.py`, `sr_weighted_calibration.py` and
  `make_round4_tables_figs.py` are disabled by default (`LEGACY_FIGURES=1` re-enables the old style).
  Final figures are produced only by `make_figures_nature_round17.py`.
- **Derived data.** `nhanes_derivation.csv` and `nhis_external.csv` are de-identified public-use extracts.
  Users are responsible for confirming that redistribution is acceptable in their jurisdiction.
